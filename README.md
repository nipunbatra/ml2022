# ES 654 · Machine Learning (2022)

Course website for ES 654 Machine Learning at IIT Gandhinagar, Semester II 2021–22 (January–April 2022):
<https://nipunbatra.github.io/ml2022/>

The site is a [Quarto](https://quarto.org) website in the same design as
[ES 667 Deep Learning](https://nipunbatra.github.io/dl-2026/). GitHub Pages serves this branch as it is, so the
site renders in place: every page's `.html` is committed next to its `.qmd`. After editing a page, run
`quarto render` and commit the result.

| File | Contents |
|---|---|
| `index.qmd` | Home: course facts, course record, module overview, questions, references, teaching assistants |
| `schedule.qmd` | Lectures: every class with its slides, recordings, notes and notebooks |
| `assessment.qmd`, `_dates.qmd` | Dates, grading policy, project ideas and quiz papers |
| `lectures/`, `notebooks/` | Slides, quiz papers and notebooks |
| `lectures/index.qmd`, `feedback/index.qmd` | Redirects from the old site's addresses |
| `styles.scss`, `course.scss`, `rail.html`, `course-theme.html`, `course-tools.html` | Shared theme |
